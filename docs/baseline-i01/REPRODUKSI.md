# Register reproduksi I01

Gunakan snapshot `index.snapshot.html` dan commit/hash pada manifest. Jalankan `node scripts/i01-baseline.cjs` dari root repo. Skrip membutuhkan Node, Chrome dan instalasi Vue workspace pada `../pdkb-vue/node_modules/vue`. Chrome memuat CDN Vue, Tailwind dan font dari jaringan. Jalankan `python scripts/i01-inventory.py` sesudahnya.

Hasil berstatus reproduced membuktikan perilaku bermasalah masih ada. Assertion memeriksa reproduksi baseline. Perbaikan nanti harus mengubah ekspektasi menjadi perilaku BPMN. Untuk cek manual, jalankan aplikasi dengan `python -m http.server 3000` dari repo, buka browser baru dan ikuti langkah di bawah. Nomor baris mengacu source kerja pada snapshot. Bukti fungsi, inspeksi kode dan tampilan browser memiliki cakupan berbeda.
